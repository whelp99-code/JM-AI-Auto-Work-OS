# AWOS Deprecation Policy v1

## Status

AI Work Automation OS v0.9.0 is **SUPERSEDED** as of 2026-08-03. Its replacement is **JM-AI Master Worker**.

## Freeze boundary

Do not start a new installation or new feature development for this package. Existing material is retained while the approved integration work is verified. This policy does not state that a receiving integration, evidence transfer, or deletion has completed.

## Evidence

The implementation start authorization is recorded in `integration-receipts/PLAN_APPROVAL.json`. Its gate validator checks the authoritative review source, the bound integration plan, and the repository identity before accepting the receipt.

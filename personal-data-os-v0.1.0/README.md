# JM Personal Data OS v0.1.0

Local-first data foundation for unified ingestion, provenance-aware search, exact duplicate detection, project classification, and backup.

## Scope
- Local/NAS files
- Gmail read-only
- Outlook read-only
- Google/Microsoft calendars read-only
- ChatGPT/Claude/Gemini export import
- Unified lexical search
- Provenance and exact duplicate grouping
- Deterministic project classification
- Local PostgreSQL backup/restore

## Safety boundary
v0.1.0 never sends, deletes, moves, or modifies external source data.
